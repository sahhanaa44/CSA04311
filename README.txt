INTERNET PROGRAMMING LAB – THREE PROJECTS
1) Extract this folder into C:\xampp\htdocs\
2) Start Apache and MySQL in XAMPP.
3) Open http://localhost/phpmyadmin, select SQL, paste database.sql, click Go.
4) Open:
   Library: http://localhost/IP_Lab_Projects/library/
   Hotel:   http://localhost/IP_Lab_Projects/hotel/
   Bus:     http://localhost/IP_Lab_Projects/bus/
This is a simplified lab demo. No real payment gateway/email sending. Use only locally.
